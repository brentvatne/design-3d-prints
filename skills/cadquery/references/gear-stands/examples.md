# Analyzed Gear Stand Examples

Real-world examples with detailed geometry analysis.

## Example 1: Elektron Digitakt Stand

**Source**: Printables.com (Fisher)
**Pattern**: End Cheek / Side Bracket

### Target Device
- Elektron Digitakt: 215 × 176 × 63 mm

### Geometry Analysis
| Property | Value |
|----------|-------|
| Dimensions | 127.4 × 74.9 × 150.0 mm |
| Volume | 164.58 cm³ |
| Surface Area | 46,304 mm² |
| Triangles | 4,828 |

### Design Notes
- Single piece per side (need 2)
- Uses VESA mount holes (M4 × 6mm bolts)
- **Warning**: Don't use screws longer than 6mm!
- 150mm height provides significant elevation

### Compatibility
- Digitakt I/II, Digitone I/II, Syntakt, Analog Heat
